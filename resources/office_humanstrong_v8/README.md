# OfficeQA sparse human Bank V8

开发候选，尚无付费效果结论。旧 V7 和全部运行产物保持原样。

六条原则共 1,060 字符，单条不超过 200 字符；V7 对应正文为 4,462 字符。按公开题意匹配，单次最多两条，无匹配则不注入指导。参考 Trace2Skill 实际注入约 96 KB，不能把此前退化简单归因于 Ours 字符更多。

四个可选 Program 分别处理连续年增长、CAGR、份额变化、绝对中点差异。复用原有计算源码，收窄各自 Schema，每次只展示适用接口。没有自动计算、强制核验或强制格式化；普通检索和临时 Python 保留。匹配规则只在人工 Bank 内，不含 UID、gold 或逐题答案。

移除 V7 的数值叶子猜测、阶段提示和独立 Bank 收尾策略。两臂均使用公共输入、普通证据打包与相同答案协议。行数或文本长度不会再被人工 Bank 单独提名为候选答案；原始工具结果仍完整保存。未改变评分或模型预算。

本轮固定 11 道适用 Test 题和 4 道未覆盖回归题，各跑 Bank/NoSkill 两臂。选择仅按公开题意、预先固定的类别顺序和 SHA256(42:task_id)，不读取 gold 或旧成绩；已有 Test 暴露及本次选择用途写入 plan，不能作为独立最终 Test 成绩。

保留口径预先固定：类别净胜才列为暂留候选，净负则移除，持平不晋升；全部失败和回归题照常报告。整个候选必须比本轮 NoSkill 多答对，且未覆盖回归组不能净退化，才算本次观察有整体增益。每类仅一至两题，不能据此宣称普遍有效或达到完整 Test 目标。

执行复用受保护的配对运行器与累计账本。本轮理论封顶 6,497,280 tokens，继承 163,443,271，总计 169,940,551，低于此前批准的 190M。冻结身份、运行前检查、费用保留和 Docker 隔离继续生效。
