# OfficeQA V10：从局部示例到完整题集检查

人工参考 Bank；不是自然学习结果。依据既有完整 Train120 轨迹与已披露的 V8/V9 开发观察修改，原 Bank、历史失败、费用与评分保留。

7 条原则共 1,264 字符，每条不超过 200 字符，每题最多 2 条；4 个可选 Program，无默认工作流，无强制复核或强制调用。通用 Agent、工具、公开原文、答案合同、收尾和评分不变。Bank-off 不注入任何资产。

实际问题对应的修改：

- 表格重复分组：仅在公开页表头有重复列名时提醒保留空单元格、年组和类别。避免把去掉非数值后的第几个数字当成固定列。
- 统计范围：先明确请求期间，再匹配带期间标签的记录。新 Program 对缺失和重复期间拒绝；额外期间明确列出并排除，不把邻近表格行加入样本。
- 样本/总体、OLS 坐标和预测误差方向通过明确参数表达。程序不猜年份坐标，不验证模型所填数值是否忠于原文；图形、缺失外部 CPI 和复杂预测仍可能失败。
- 保留已观察到收益的归一化小数能力。增长率家族在旧小样本持平，只能算未定，作为明确条件的候选重新评价；不宣称其有效。
- CPI 指导只在相关任务出现，不能代替缺失原始指数。

公开适用性扫描覆盖 Train 51/120、Test 36/102；未覆盖题继续原生求解。这是路由覆盖率，不是准确率。否定的通胀调整措辞不触发 CPI 指导。判断只用公开题面和源页结构，资产不含 UID、gold、题目数值或按题切换。

## 本次冻结实验

用户明确批准累计 262M。历史已用及保留 165,095,409 tokens；同一 Bank 的 Train120 与 Test102 各做新的 Bank/Bank-off 双臂，共 444 次，每次上限 216,576，新增理论上限 96,159,744，累计理论上限 261,255,153。HTTP 按现有循环与重试上限计算。

先完整 Train120，结算后自动完整 Test102，不依据 Train 分数筛题或更换 Bank，不另跑付费小样本。遇基础设施、未知计费或冻结身份失败停止。两段都是冻结人工 Bank 的求解测试：不更新 Bank、不拆 Ours 的 Train、不重启自然学习、不把测试结果晋升为学习资产。

全部 Train 与 Test 均已有开发接触；报告须标明开发暴露，不能包装为独立盲测。必须报告全量逐题增减、同设置对照、Program 使用和费用；不能把小样本胜出或达到 65% 单独称为资产增益。

启动入口：`experiments/run_office_humanstrong_v10.py prepare-all/launch-all/status-all --root <独立目录>`。准备前必须固定干净源码。程序依旧需要 Agent 自主选择；算术执行成功不等于原文取数正确或最终评分正确。
