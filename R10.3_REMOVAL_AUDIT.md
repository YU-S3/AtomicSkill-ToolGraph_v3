Status: development verification, not a claim of formal release.

|---|---|---|
| Local role sorting as equivalence authority | Full typed relation graph and verified map | Old deterministic identity only within explicit independent learning ablation |

| Building prompt before final native table | Finalize original native specs first, then project exact duplicates | Missing/conflicting native definitions are retained; no guessed authority |
| Repeated full schema/description in payload and native table | Exact typed reversible substitution | Support templates without identical native definition, all extra semantics |
| Long repetitive scope prompt | Replacement short-step text | Scope, intent, completion, terminal, current evidence and shared resources |

No global deduplication of guideline steps/notes, no guideline revision table,
default pointer, automatic retirement, text-action parser, whole upstream agent,
new model call, benchmark navigation rule or long Runtime session was added.

Existing correctly functioning feedback and negative-memory logic was retained;
different failures/scopes are not deleted to claim prompt savings. Original
already-satisfied checks, Agent bootstrap, lawful automatic successor entrance,
terminal pure-tail handling and failure rollback remain in their existing paths.

The historical prompt module is used only by explicit C01/C00 diagnostics. It is
not a fallback Planner or parallel production authority. Diagnostic program
masks act at exposure and automatic-entry boundaries, never by returning fake
success from ToolRunner. Original regression tests were not removed to mask
failures. Added fixtures retain original Atomicizer/admission/EvidenceStore/replay
checks; controlled normalized-source fixtures are identified in the test module.
