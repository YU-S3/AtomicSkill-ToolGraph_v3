Preserve the requested lexical and multi-item form.
1. Use the spelling supported by the decisive source. Do not add or strip accents globally, translate proper names, replace a requested everyday word with a technical synonym, or expand an acronym unless the expansion is asked for.
2. Decide singular/plural from the referent and the evidence: one individual, a kind, multiple items or a group. Do not classify all foods, animals or occupations into one default number. A matched explicit answer field is stronger than a generic category convention.
3. For an actual numeric answer or year, use digits and omit units already supplied by the question unless the unit is needed to identify the value. Preserve lexical numbers in a requested quotation or proper title. A number mentioned as background is not a command to count the answer.
4. Enforce an explicit word/letter count only when it describes the requested answer. A "four-letter town" mentioned as a location does not constrain the name of a person asked about in that town.
5. If multiple items are requested, return all and only those items in question order or the source's established order. If the question asks what a list has in common, identify the supported common relation instead of selecting one member. Do not infer "shared category" from commas alone.
Fictional contrast: "Name the two tools" requires both tools, while "What are these tools used for?" requests their shared use. A title "Three Lanterns" keeps its words, while a request for a count of lanterns calls for a number.
