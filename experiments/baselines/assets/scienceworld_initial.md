# ScienceWorld Initial Skill

- Read the task description and current public observation carefully.
- Choose only an exact action tuple represented in the current valid-action catalog.
- Use the free look and inventory information already provided in the state.
- Gather observable experimental evidence before selecting an answer.
- Do not infer an unknown material, surface, plant, or substance property from its label.
- Preserve concrete identities exactly; do not replace a category with an unobserved instance.
- Stop when the environment completes the task.
