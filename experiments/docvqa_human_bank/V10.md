# Independent rule search

v9 is a reference, not a required starting asset set. Its two Test runs scored
187/201, with twelve correctness flips between runs. Broad normalization and
longer guidance have not demonstrated stable superiority. Those records identify
failure modes and regression risks; they are not answer lookup rules.

v10 stores the 536-character reference core and individually selected short rules
as separate immutable Skills. The default has no specialist rule. Each direction
has two alternative wordings; at most one wording per direction is allowed.
Public question text selects at most one specialist. No task ID or gold is used
by the runtime. Existing versions retain their original Banks and interfaces.

The first bounded search compares core-only, wording A and wording B on the same
six tasks in each of three directions: entity boundary, table measure selection,
and raw number handoff to the formatter. Each arm runs twice with reversed arm
order in the second repeat. The selected tasks include observed failures and
previously correct protection cases. All inputs and choices are frozen before
calls. These are exploratory Test subsets, not estimates of whole-Test accuracy.

Original images, model settings, scorer, per-task caps and typed submission are
the same within each pair. Cropping is disabled in all first-search arms to isolate
the short rules and handoff behavior. The real formatter Program is retained;
no additional model turn follows a successful Program submission. A crop-enabled
combined Bank would require its own later evaluation.

Planned first search: 3 directions x 3 arms x 6 tasks x 2 repeats = 108 task
evaluations, within 800,000 new tokens and 110 HTTP. All historical charges and
unresolved reservations carry forward under the approved cumulative 14M tokens
and 2,400 HTTP. Stop on infrastructure, billing or budget errors; no automatic
replay or extra repair allowance.

All arms run regardless of interim score. A wording only advances if both paired
repeats have no observed regressions or added empty answers, and it gains at least
one correct answer in each repeat. No effect or conflicting effects mean it does
not advance. If both wordings pass, rank by the smaller paired gain, then total
gain, then fewer guidance characters. Report every result, including losses.
Advancement is only eligibility for broader combination/protection checks, not a
production promotion or a claim that 95% is reached. Do not compose or launch a
full Test solely from these six-task results.

These are externally authored experimental assets, not naturally learned Ours
Skills. Production training, scoring and benchmark split logic are unchanged.
