# OfficeQA R1 修复与启动

本轮依据用户指定的 OfficeQA R1 文档修复检索、公共结果窗口、收尾预算与操作学习目录。数据划分、评分、Program 晋升条件、修复次数和每题预算保持原合同；不复现其他方法。

## 修改

- glob 共享 grep 的授权 txt 集合，按 POSIX 分段匹配；`**` 可匹配零级目录，普通通配符不跨目录，大小写固定，拒绝越界路径和外部符号链接。
- 注册原生结果协议，只投影其根部 Host 元数据。原始结果、审计和来源 hash 留在 Host；Agent 引用、read_result、Program RPC、学习输出 selector 与收尾使用同一公共字段规则。计算 JSON 内的同名业务字段不删除。
- 文本按 Unicode 字符、数组按完整元素分页，记录实际范围和内容 hash。收尾按来源与区间去重，read_result 页保留源引用；收尾请求在执行 checkpoint 中固定，以保持付费响应恢复身份。
- Office 收尾完整 Provider payload 上限 16,384 字节，输出 2,048，正常预留 18,432。Runtime 默认仍为 32,768；只在实际账本余量不足时缩小本轮输出，低于 8,192 则收尾。父任务、Train 池、角色和 whole-run 限额共同约束，重规划和 HTTP 重试保留收尾额度及请求位置。
- Office 普通 Extractor 为 disabled/8192，使用命名 submit_learning；结构修复仍 disabled/2048、最多一次。每个 case 最多四张目录卡，文件发布和实际代码代表优先；stdout observation 可引用，执行元数据不作为业务输出。超限先裁可选历史，再裁低优先级卡；Builder 仍只拿已绑定的完整源操作。
- 新材料和模型视图有独立版本。已确认的本地准入拒绝单独记录，不计为未知支付；旧 pilot 不回填。
