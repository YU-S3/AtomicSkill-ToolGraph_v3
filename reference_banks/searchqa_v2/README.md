# SearchQA manual Bank v2

This is an explicitly human-authored revision informed by failures of the first
Test1400 reference run. It is not naturally learned Ours and is not an unseen-Test
evaluation. Runtime, public inputs, scorer, limits and model parameters are unchanged.

Twelve Skills clarify elliptical clues, requested answer constituents, historical
scope and the narrow applicability of the existing Programs. The DOC parser reads
TLE titles separately from PAR bodies while retaining exact text/offsets. Evidence
windows preserve line-wrapped relations and diversify across documents. The parent
and birthplace extractor remains deliberately narrow; no generic semantic solver
is claimed. There are no task IDs, entity-answer mappings or evaluator reads.

Build a new importable package from the original package using build.py. Skill,
Implementation and Workflow IDs are versioned; modified Programs have new content
IDs. parent_id and parent_bank_sha256 record provenance. All Programs remain
candidates until independent real Docker reference checks authorize this control.
This does not change Ours qualification.
